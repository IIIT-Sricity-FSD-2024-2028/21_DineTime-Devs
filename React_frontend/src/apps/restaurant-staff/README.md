# Restaurant staff portal contribution

This folder contains staff authentication and access requests, the daily
dashboard, reservation lookup, guest check-in, table operations, and staff
profile management.

- `app/App.jsx`
- `api/staffApi.js`
- `context/StaffContext.js`

  profile

  request, and shared styles
- `utils/format.js`, `utils/images.js`, and staff image assets
