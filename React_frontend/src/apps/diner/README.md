# Diner portal contribution

Tejdeep Reddy — Diner

This folder contains the diner-facing portal. It is responsible for account
access, restaurant discovery, reservations, payments, orders, profile/settings,
and support.

## Files developed or modified

- `app/App.jsx`
- `api/dinerApi.js`
- `context/DinerContext.js`
- `pages/` — authentication, browsing, search, restaurant details, booking,
  payment, reservations, profile, settings, menu, and support
- `components/` — layout, navigation, forms, restaurant cards, maps,
  reservations, payments, orders, feedback, and support
- `styles/` — diner page and feature styles
- `utils/` — distance, formatting, image helpers, and diner assets
